# 跨来源字段映射与核对

## 当前原则

Tushare是字段目录的参照，不是数值或公式标准。统一字段的业务含义与计量单位；同类指标允许供应商采用自己的计算算法、调整项和展示精度，不因数值不同而撤掉来源。

每个数值在`field_sources`中保留来源；查询结果的`fields.<字段>.source_definitions`给出来源列名、原单位和来源口径。`roe`可以返回来源提供的ROE，并明确加权、摊薄、平均等口径。`roe_waa`仍专门表示加权ROE。调用者若需要精确算法，应指定来源并阅读说明。

仍不能混用：单季度与累计、日换手率与月换手率、普通流通与自由流通、历史日期与未来报告期，以及年度与TTM。公式差异允许保留，真正不同的业务含义和日期不能互换。

完整可执行配置与所有空位见[总字典](data-dictionary.md)。目标单位尚未核实的字段继续保留“未确认”。

依据：[iFinD官方入口](https://mcp.51ifind.com/)、`get_security_indicators`工具定义、历史日期配对实测。

## wind

恢复普通ROE，固定请求并注明摊薄口径；加权ROE仍单独保留。存货周转天数、自由流通股、流通A股、年度/TTM股息率不再因与Tushare数值不同被排除。

PE/PS曾返回百分比表示的比值。执行器按实际单位动态换算：2084.2041%对应20.842041倍；若已经返回“倍”，不再除100。转换由字典`unit_multipliers`驱动，源列和换算说明均可查。

依据：[Wind入口](https://market.windalice.com/)、`get_stock_fundamentals`工具定义及实际列名、单位。自然语言返回可能改变表头，精确别名来自真实返回；不把未知列强行猜成目标字段。

## akshare

恢复存货周转天数、保守速动比率、自由现金流每股值、每股EBIT、ROA、ROIC、扣非ROE、权益比率、期间费用率、现金/销售收入、营业周期、PS-TTM及流通A股等，计算算法采用东财或新浪定义。

例：新浪产权比率以百分数返回，转换为倍；其中权益分母采用新浪口径。`roe`继续对应新浪平均ROE，`roe_waa`对应东财加权ROE。茅台2024三季报的平均ROE为26.833039%，Tushare为26.833%，加权与年化指标则各不相同；这用于说明口径，不作为强制数值对齐标准。

依据：[官方财务文档](https://akshare.akfamily.xyz/data/stock/stock_finance.html)、[官方估值文档](https://akshare.akfamily.xyz/data/stock/stock_valuation.html)、[新浪SDK源码](https://github.com/akfamily/akshare/blob/main/akshare/stock_fundamental/stock_finance_sina.py)、[东财估值SDK源码](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_value_em.py)。

## tdx

恢复PS-TTM、自由流通股，保留来源算法和该列自身截止日期。此前已接入稀释EPS、单季EPS、单季扣非利润、收盘及普通换手率。

仍留空的主要例子：查询2025-11-06返回20251231报告期的股本；日自由换手率被解析为月换手率；普通量比被解析为DBLB技术指标。这些属于日期或含义不同，不是算法差异。

依据：通达信`tdx_api_data`、`tdx_indicator_select`工具定义及真实响应。`fixedTag=00101`与`00102`分别对应累计和单季度利润表。
