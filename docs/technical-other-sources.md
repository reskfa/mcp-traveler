# Wind、iFinD、AKShare 技术指标接入边界

核实日期：2026-11-16。这里以现有 300 个技术字段为映射目录，保留各来源自己的算法、参数和复权定义；相似名称不代表数值等价。

## AKShare

本机安装版本为 1.18.14，本次查阅的[官方股票其他数据文档](https://akshare.akfamily.xyz/data/stock/stock_other.html)显示 1.20.65。两者的“技术指标”接口均为同花顺技术选股榜单。本次没有找到能够补齐这 300 个目录字段的原生个股历史指标数值接口，因此新增映射为 0；这是当前已核实范围的结论，不表示未来或目录外没有其他接口。

实际调用 `stock_rank_lxsz_ths()` 返回 113 行，包含连涨天数，但没有历史日期入参或输出快照日期，只覆盖入选股票，不能用作历史 `updays`，也不能把未入选证券当作 0。其他近似接口同样不能直接映射：

|接口|不接入历史技术字段的原因|
|---|---|
|`stock_rank_lxxd_ths`|最新连跌榜单，不能补齐历史 `downdays`|
|`stock_rank_xstp_ths` / `stock_rank_xxtp_ths`|只返回突破／跌破某均线的股票，不返回均线数值|
|`stock_rank_cxg_ths` / `stock_rank_cxd_ths`|返回前期高／低点及其日期，不等价于目录中的 `topdays` / `lowdays`|

可以另建“本地派生”来源，在 AKShare 日线上计算指标，但须明确记录算法、预热窗口、缺失日和复权方式。本轮未实现，也不将其计作 AKShare 原生支持。

## Wind

新增 21 个独立的 `wind_*_native` 字段，如 `wind_ma_20_native`、`wind_kdj_k_native`，调用 `get_stock_price_indicators`。它们是最新交易日的原生技术快照，可含盘中变化，不能补齐其他来源的历史字段。完整计算参数与复权方式未披露，不支持 `parameters` 覆盖，只接受 `adjust="native"`。

真实样本为 `600519.SH`，来源实际交易日为 2026-11-17。执行器核对证券、实际交易日、交易时间、列和单位；显式日期区间不含该实际交易日时失败，不把请求日期写到快照上。该样本中 12 项单位由来源明确返回，9 项按指标定义推断并标记；OBV 单位未明确，暂未接入。

历史接口 `get_stock_technicals` 已接入23类、32个 `wind_history_*` 字段：MA、MACD三分量、KDJ三分量、RSI、BOLL三轨、CCI、ATR、BIAS、ROC、WR、OBV、EXPMA、BBI、DMI四分量、TRIX、PSY、MTM、DMA、SAR、MFI、AR、VR、CR。原始真实样本为 `600519.SH` 在2026-11-10至11-13的四个交易日，32个字段均通过主字典回放。统一 MCP 实查 MACD三分量、HTTP 实查 MA10、KDJ三分量、BOLL三轨均成功返回四日；浏览器界面另实查RSI12，成功返回四日并核对周期12。

取法由字典 `query_template`、返回列、分量选项和参数映射驱动，通用执行器 `gateway/wind_history.py` 处理同表或分量多表。MA、RSI周期可调；MA10、MA20及RSI6、RSI12均真实核实。其他族沿用来源默认，已返回的参数记录并核对，未披露项不假设。BOLL为26日、带宽2；MACD未回显完整周期，不能标成确定的12/26/9。复权未披露时只称来源原生，保留原始结果。

裸英文VR、CR曾被解释成成交量/成交额运算，正式取法改用已实测的中文全名；BRAR混查的BR与AR重复，单独BR无数据，因此BR留空，不用AR替代。历史单位未由来源直接声明：价格量纲等按定义标注并说明推断，VR/OBV缩放未确认，保留来源原值。历史返回必须含实际证券、日期及目标列；已声明参数、分量、频率冲突时拒绝，不能用快照或请求日期补值。正常空表和个别交易日缺值保留。

## iFinD

新增 28 个独立 `ifind_*` 原生日线字段，如 `ifind_ma`、`ifind_kdj_k`、`ifind_boll_upper`。通过 `get_security_indicators` 查询，限 A 股不复权日线，接受 `adjust="native"` 或 `none`。各字段的参数名、默认值、范围以 profile 为准；均线默认 20 日，不把所有指标统一套用同一套参数。

执行器核对每个分量自己的 `indicators_params`，包括参数值、计算周期、复权方式，并核对显式表格中的证券和日期。近似名称、其他分量的参数、没有日期或未实际返回的分量不能代替目标证据；不以行情本地计算补值。上游可能省略部分指定指标，此时报告失败。

真实样本请求为 `600519.SH` 的 2026-11-10 至 2026-11-11，表格返回这两个历史日期；参数元数据里的“交易日期=最新”未单独作为日期证据。

这 28 项只描述本轮已经得到原生返回和参数证据的分量，不代表所有同名指标、参数组合、股票和历史区间均已验证。KDJ 的 K、D、J 均已有真实返回；其他缺项继续保留。

本轮 iFinD 的真实返回没有单位标签；27 项根据指标定义与真实量级标注单位，并明确为 `definition_inferred`，不是来源直接声明。OBV 缩放仍不明确，保留来源原值，不推断为股或手。

参数覆盖也不是每次都会被上游正确执行：一次 MA10 请求实际返回周期 5，执行器已拒绝该结果。参数可提交，结果必须核对后才交付。
