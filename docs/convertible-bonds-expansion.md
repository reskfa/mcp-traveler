表中是字典配置覆盖，并非每次请求、每只券都能返回。真实 MCP 结果保留每字段来源与缺失值。完整字段映射、单位及未映射原因以 [数据字典](data-dictionary.md) 为准。

## AKShare

新浪档案与摘要都是当前资料；集思录当前赎回表只补当前档案，不把强赎状态或概率当公告历史。新浪日线按返回日期切片，成交量因单位未核实未映射。东财估值实际 SDK 因 15 列变 13 列失败；兼容适配继续访问 AKShare 官方实现使用的同一 `RPTA_WEB_KZZ_LS` 接口，按 JSON 字段名解析，不按列序硬套。请求证券身份、日期、8000 条上限均检查。东财估值可能含上市前日期，保留其实际日期，不伪装为成交日。

## iFinD

使用债券市场原生指标。实际表格内的日期，或该指标自身返回参数内的明确日期，才可以给数值定日；请求文本日期不能作为证据。合同原文可能换行，解析保留完整文本。金额按返回单位统一为元；百分数不除以 100。

`ytm_provider` 单列保存上游“到期收益率”或“纯债到期收益率”；实际返回计算方法时按原文保留（已见“央行规则”），缺少时按未知，不自行补写。未证明税种，不能填 `ytm` 或 `ytm_after_tax`。历史 `cb_daily.conversion_price` 已以带实际交易日期的“转股价格”核实，单位元/股；不因此把当前档案快照回填为历史。历史换手率保留上游百分数。成交量明确请求并核实“单位设置=手”；成交额按实际表头单位换算。评级只作当前快照，禁止据包含未来评级信息的文本回填历史。

## TDX

固定 `tdx_kline` 设置日线、不复权。实际请求 1000 条只返回 700；因此按 700 偏移翻页，第二页实得 472 条，历史覆盖兴业转债上市日 2022-01-14 至 2026-11-18。分页检查日期前移、证券代码、市场、周期，避免重复页或错券。

`RawAmount` 为元；固定 `tdx_quotes` 对同券明示“成交量70万手”，`BaseInfo.Unit=10`，同日 `HQInfo.Volume=704525` 与 K 线 `RawVolume=704525` 一致，成交量按手原值保留。K线内的 `AttachInfo` 只用于当前简称，不拿最新价格或日期回填历史。`LTGB` 等字段含义未核实，不作转债余额推断。

`tdx_indicator_select` 只接受 AG/ZS/JJ；合法 AG 范围实查转债档案及估值均返回 HTTP 400“未找到相关实体”。未接入其转债估值、条款和公告事件，保留空缺。

## 证据与复现

- 三来源完整本地 MCP 调用与真实返回：`local/convertible_expansion/mcp_three_sources.json`。
- 自动补齐调用：`local/convertible_expansion/mcp_automatic_mixed.json`。
- 原始探测：同目录 `akshare_*`、`ifind_*`、`tdx_*_raw.json`。
- 离线回归样本：`tests/fixtures/akshare_cb_dictionary.json`、`tests/fixtures/ifind_convertible/`、`tests/fixtures/tdx_cb_kline.json`。

这些探测没有写入个人常用字典；正式取法进入项目内置字典 `gateway/data/dictionary.json`。

## 合同原文与历史公告的入口

网页“可转债档案与合同条款”可一键选择赎回、回售、下修原文；对应 `cb_basic` 的 `call_clause`、`put_clause`、`reset_clause`。来源可能仅返回其中部分，缺失保留空。实测同一条款问句也可能只返回是否存在条款或不返回原文，这些结果不能替代合同文本，不宣称三类原文均已稳定取到。

“可转债历史公告事件”对应 `cb_clauses`，按实际公告日期返回。iFinD、TDX 尚未接入同口径事件；明确指定时返回 `status=unsupported` 和所请求来源，不把未调用上游伪装成查询失败或没有公告。可改查当前合同原文，默认自动选择支持的来源。已接入接口的真实上游错误仍按失败返回。
